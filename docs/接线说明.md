# 接线说明 (天猛星 MSPM0G3507 48Pin)

## 硬件清单

| 设备 | 型号 | 说明 |
|------|------|------|
| 主控板 | 天猛星 MSPM0G3507 48Pin | Cortex-M0+, 32MHz |
| 电机驱动板 | WHEELTEC D153C | TB6612 驱动 |
| 电机 x2 | MG310 直流减速电机 | 带编码器, 6根线/个 |
| 蓝牙模块 | HC-04 | 串口透传, 115200 baud |
| 调试器 | CMSIS-DAP | SWD 下载调试 |
| 电源 | 7.4V 电池 | 为 D153C VM 提供电机电源 |

---

## MSPM0G3507 引脚分配总表

| 引脚 | 功能 | 接往 |
|------|------|------|
| PA8  | GPIO 输入 | 电机A 编码器 A 相 (E1A) |
| PA9  | GPIO 输入 | 电机A 编码器 B 相 (E1B) |
| PA10 | UART0_TX | HC-04 RX + USB-TTL RX |
| PA11 | UART0_RX | HC-04 TX |
| PA13 | AIN2 | D153C AIN2 (电机A 方向) |
| PA14 | AIN1 | D153C AIN1 (电机A 方向) |
| PA16 | BIN1 | D153C BIN1 (电机B 方向) |
| PA17 | BIN2 | D153C BIN2 (电机B 方向) |
| PB2  | CCP0 (TIMA1) | D153C ENB (电机B PWM) |
| PB3  | CCP1 (TIMA1) | D153C ENA (电机A PWM) |
| PB8  | GPIO 输入 | 电机B 编码器 B 相 (E2B) |
| PB9  | GPIO 输入 | 电机B 编码器 A 相 (E2A) |
| PA23 | GPIO 输出 | 灰度传感器 AD0 (通道切换 LSB) |
| PA24 | GPIO 输出 | 灰度传感器 AD1 (通道切换) |
| PA25 | GPIO 数字输入 | 灰度传感器 OUT（M1 暂按数字模式诊断，电气类型待台架确认） |
| PA26 | GPIO 输出 | 灰度传感器 AD2 (通道切换 MSB) |
| PA21 | UART2_TX | JY61P RX (可不接) |
| PA22 | UART2_RX | JY61P TX |
| 3.3V | 电源 | D153C VCC + STBY + 编码器 VCC + 灰度传感器 VCC |
| GND  | 地 | D153C GND + 编码器 GND + 灰度传感器 GND |

## 感为八路灰度传感器接线

| 传感器信号 | MSPM0G3507 | 说明 |
|-----------|------------|------|
| GND | GND | 共地 |
| VCC | 3.3V | 当前实物已验证使用 3.3 V |
| OUT | PA25 | 当前固件按 GPIO 数字输入扫描；是否应切换 ADC 由 M1 台架波形确认 |
| AD0 | PA23 | 通道地址 LSB, GPIO 输出 |
| AD1 | PA24 | 通道地址, GPIO 输出 |
| AD2 | PA26 | 通道地址 MSB, GPIO 输出 |
| EN | GND | 低电平使能 |

## MSPM0G3507 → D153C 接线

| MSPM0G3507 | D153C | 功能 |
|------------|-------|------|
| PB3 | ENA | 电机A 速度 PWM |
| PB2 | ENB | 电机B 速度 PWM |
| PA14 | AIN1 | 电机A 方向 |
| PA13 | AIN2 | 电机A 方向 |
| PA16 | BIN1 | 电机B 方向 |
| PA17 | BIN2 | 电机B 方向 |
| 3.3V | VCC | TB6612 逻辑电源 |
| 3.3V | STBY | 待机使能, 必须拉高 |
| GND | GND | 共地 |

## 电机线 (以单个电机 A 为例)

| MG310 线色 | D153C / MSPM0 | 说明 |
|-----------|---------------|------|
| 红线 | D153C AO1 | 电机正极 |
| 黑线 | D153C AO2 | 电机负极 |
| 绿线 | MSPM0 3.3V | 编码器供电 |
| 蓝线 | MSPM0 GND | 编码器地 |
| 黄线 | D153C E1A → MSPM0 PA8 | 编码器 A 相 |
| 白线 | D153C E1B → MSPM0 PA9 | 编码器 B 相 |

> 电机B 同理：红线→BO1，黑线→BO2，黄线（E2A）→PB9，白线（E2B）→PB8。

## 蓝牙 HC-04

| HC-04 | MSPM0G3507 |
|-------|------------|
| TX | PA11 (UART0_RX) |
| RX | PA10 (UART0_TX) |
| VCC | 3.3V |
| GND | GND |

> USB-TTL 调试时：USB-TTL RX 接 PA10 监听；若需要向主控发送，USB-TTL TX 接 PA11，并避免与 HC-04 TX 同时驱动该线。

## TB6612 控制逻辑

| AIN1 | AIN2 | 电机状态 |
|------|------|---------|
| HIGH | LOW  | 正转 (代码已根据实际接线交换) |
| LOW  | HIGH | 反转 |
| HIGH | HIGH | 制动 |
| LOW  | LOW  | 滑行 |

- PWM 频率: **4kHz** (32MHz / 8 / 1000)
- PWM 范围: **0~999**

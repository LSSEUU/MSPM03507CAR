# 接线说明（立创·天猛星 MSPM0G3507-64P）

## 硬件清单

| 设备 | 型号 | 说明 |
|------|------|------|
| 主控板 | 立创·天猛星 MSPM0G3507-64P | Cortex-M0+，32 MHz；原理图见 `立创·天猛星MSPM0G3507开发板原理图.pdf` |
| 电机驱动板 | WHEELTEC D153C | TB6612 驱动 |
| 电机 x2 | MG310 直流减速电机 | 带编码器, 6根线/个 |
| 灰度传感器 | 感为无 MCU 八路灰度 | 74HC4051 选通、模拟 OUT |
| 陀螺仪 | JY61P | UART 自动发送角度帧 |
| 显示屏 | SSD1306 OLED | 软件 I²C |
| 串口模块 | HC-04 / 独立 USB-UART | UART0 诊断；当前台架证据来自独立 USB-UART |
| 调试器 | CMSIS-DAP | SWD 下载调试 |
| 电源 | 7.4V 电池 | 为 D153C VM 提供电机电源 |

## MSPM0G3507 引脚分配总表

| 引脚 | 功能 | 接往 |
|------|------|------|
| PA8  | GPIO 输入 | 电机A 编码器 A 相 (E1A) |
| PA9  | GPIO 输入 | 电机A 编码器 B 相 (E1B) |
| PA10 | UART0_TX | HC-04 RX + USB-TTL RX |
| PA11 | UART0_RX | HC-04 TX |
| PA13 | AIN2 | D153C AIN2 (电机A 方向) |
| PA14 | AIN1 | D153C AIN1 (电机A 方向) |
| PA16 | BIN1 | D153C BIN1 (电机B 方向) |
| PA17 | BIN2 | D153C BIN2 (电机B 方向) |
| PB2  | CCP0 (TIMA1) | D153C ENB (电机B PWM) |
| PB3  | CCP1 (TIMA1) | D153C ENA (电机A PWM) |
| PB8  | GPIO 输入 | 电机B 编码器 B 相 (E2B) |
| PB9  | GPIO 输入 | 电机B 编码器 A 相 (E2A) |
| PA23 | 开漏 GPIO 输出+输入回读 | 灰度 AD0；同时为 VREF+，经 C44=1 µF 耦合 PA21/VREF−，高电平使用内部上拉 |
| PA24 | GPIO 输出 | 灰度传感器 AD1 (通道切换) |
| PA25 | ADC0 A0_2 | 灰度传感器模拟 OUT；数字输入缓冲不启用 |
| PA26 | GPIO 输出 | 灰度传感器 AD2 (通道切换 MSB) |
| PA21 | 高阻输入 | 不启用 UART2_TX、不连接 JY61P RX，避免经 C44 耦合 PA23 |
| PA22 | UART2_RX | JY61P TX |
| PA28 | 软件 I²C SDA | SSD1306 OLED SDA |
| PA31 | 软件 I²C SCL | SSD1306 OLED SCL |
| 3.3V | 电源 | D153C VCC + STBY + 编码器 VCC；不作为当前灰度模块电源 |
| 5V | 电源 | 当前灰度模块 VCC；与主控共地，接入 PA25 前必须确认 OUT≤3.3 V |
| GND  | 地 | D153C GND + 编码器 GND + 灰度传感器 GND |

## 感为八路灰度传感器接线

| 传感器信号 | MSPM0G3507 | 说明 |
|-----------|------------|------|
| GND | GND | 共地 |
| VCC | 5V | 当前实物按厂家要求供电；不得与 3.3 V 电源短接 |
| OUT | PA25 / A0_2 | 模拟量 ADC 输入；当前实物接入前实测全范围不超过 3.3 V |
| AD0 | PA23 | 开漏输出；高电平由内部上拉形成并回读，避免经 C44 向 PA21 注入推挽瞬态 |
| AD1 | PA24 | 通道地址, GPIO 输出 |
| AD2 | PA26 | 通道地址 MSB, GPIO 输出 |
| EN | GND | 低电平使能 |

当前仓库固件已完成八路 ADC 与黑白响应验收：连续四轮 span=3182–3189、errors=0。更换模块、改变供电或调整输出电路后必须重新测量 OUT；PA25 不可直接承受 5 V。灰度阈值标定与循迹位置算法留到 M2。

## 电机线 (以单个电机 A 为例)

| MG310 线色 | D153C / MSPM0 | 说明 |
|-----------|---------------|------|
| 红线 | D153C AO1 | 电机正极 |
| 黑线 | D153C AO2 | 电机负极 |
| 绿线 | MSPM0 3.3V | 编码器供电 |
| 蓝线 | MSPM0 GND | 编码器地 |
| 黄线 | D153C E1A → MSPM0 PA8 | 编码器 A 相 |
| 白线 | D153C E1B → MSPM0 PA9 | 编码器 B 相 |

> 电机B 同理：红线→BO1，黑线→BO2，黄线（E2A）→PB9，白线（E2B）→PB8。

## TB6612 控制逻辑

| AIN1 | AIN2 | 电机状态 |
|------|------|---------|
| HIGH | LOW  | 正转 (代码已根据实际接线交换) |
| LOW  | HIGH | 反转 |
| HIGH | HIGH | 制动 |
| LOW  | LOW  | 滑行 |

- PWM 频率: **4kHz** (32MHz / 8 / 1000)
- PWM 范围: **0~999**

当前功能状态和验证结果统一见仓库根目录 `STATE.md`；本文只维护接线事实。

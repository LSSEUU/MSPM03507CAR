## 资料类型与维护边界

- `STATE.md`：只写当前结论、活动待办、安全边界和证据入口；不堆叠长日志或已关闭问题的时间线。
- 日期验证记录：保留命令、测量、失败原因、修复复测和构建数据；结论变化时同步回 `STATE.md`。
- 使用/接线指南：写操作者实际需要的步骤和安全约束，不承担里程碑状态汇总。
- 参考 PDF：只在引脚、电气或芯片细节确实需要时读取，不作为固件当前状态来源。

硬件或固件状态变化时同步 `STATE.md`；只有形成新的可复核测试、构建或台架证据时才追加验证记录。单纯文档整理要明确标注“无功能变化”，不得写成重新验证。

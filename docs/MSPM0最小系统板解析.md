# 天猛星 MSPM0G3507-64P 硬件约束摘要

本文只提炼会影响当前固件的开发板事实。元件值、网络连接和复用关系以 `立创·天猛星MSPM0G3507开发板原理图.pdf` 为最终依据。

## 固件基线

- MCU：MSPM0G3507，64 引脚封装。
- 当前固件系统时钟：32 MHz；不要仅因板上存在外部晶振就修改固件时钟配置。
- 板级配置唯一来源：`Source/ti_msp_dl_config.c/.h`。
- SWD：PA19（SWDIO）、PA20（SWCLK），应用不得重新配置。
- BSL 调用输入：PA18，应用不得重新配置；载板蜂鸣器网络与它复用，下载异常时先排查上电状态和物理连接。

## 与当前外设相关的复用约束

### PA21、PA22、PA23 与灰度/JY61P

- PA22 配置为 UART2_RX，连接 JY61P TX，9600 baud。
- PA21/VREF− 保持无上下拉高阻，不连接 JY61P RX。
- PA23/VREF+ 用作灰度地址 AD0。开发板 C44（1 µF）跨接 PA21/VREF− 与 PA23/VREF+，因此 PA23 高电平采用释放引脚后内部上拉的方式，避免推挽跳变经 C44 耦合到 PA21。
- 原理图上的 R4 默认不装；不要假定 PA21 已经通过它接到 AGND。
- C33 属于 NRST 复位网络，不连接 PA23。

### 灰度模拟输入

- PA25 使用 ADC0 A0_2 采集 74HC4051 的 OUT，数字输入缓冲保持关闭。
- 当前灰度模块按厂家要求使用 5 V 供电并与主控共地；当前实物 OUT 已测得不超过 3.3 V。更换模块或供电方式后必须重新测量，PA25 不是 5 V 容忍输入。

### 串口与下载

- UART0：PA10 TX、PA11 RX，115200 8N1，用于诊断和 HC-04/USB-UART。
- 当前独立 DAPLink 未连接 RST 也可稳定下载；若再次出现 SWD 连接故障，先确认 3.3 V、共地、线缆和上电次序，不把一次调试端口失败直接归因于应用代码。

## 电源与指示灯

- 固件只把已确认的 MCU 可控信号声明为外设。当前载板可见 LED 是电源指示灯，不作为软件状态 LED。
- DAPLink、USB-UART、主板和电机电源并存时必须共地，并避免多个 3.3 V/5 V 电源相互反灌。

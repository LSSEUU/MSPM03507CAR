# OUT.8IR.B 校准与通道资格验证手册

本手册适用于使用 PA24/PA26 软件 I²C 的 OUT.8IR.B 八路红外巡线模块。

## 1. 两种操作的边界

- 模块物理按键校准决定 OUT.8IR.B 内部的黑线判定阈值，必须首先完成。
- 固件原有的两阶段“灰度标定”接口继续保留，用作八路通道、安装方向、通信和 Flash 链路的资格验证；它不会向模块写入阈值。
- I²C 只提供数字掩码。固件为兼容旧接口，将检测到线转换为 `1`，背景转换为 `4094`；页面中的 ADC 字段不再代表原始模拟量。

## 2. 接线和上电检查

| OUT.8IR.B | MSPM0G3507 |
|---|---|
| VCC | 稳定 5 V |
| GND | GND，共地 |
| SDA | PA24 |
| SCL | PA26 |

IR1–IR8、TXD、RXD、旧灰度网络 PB1/PA25 均不连接。连接 MCU 前测量 SDA/SCL 空闲高电平，必须不超过 3.3 V。上电后等待至少 3 秒；PWR 应正常，ERROR 若亮起则先完成物理校准。

## 3. 模块物理按键校准

1. 固定最终安装高度并清洁探头。
2. 将全部探头置于赛道背景上，按厂家说明长按按键完成第一阶段。
3. 将全部探头同时覆盖足够宽的黑线，再长按按键完成第二阶段。
4. 确认 ERROR 熄灭；把黑线逐路移动经过探头，确认对应指示灯和输出变化。

模块会保存校准结果，重新上电不需要自动重复。如果更换赛道材料、安装高度、模块或环境光发生明显变化，应重新执行。

## 4. 固件资格验证

开始前车辆必须处于 `IDLE`、无 Safety 故障、轮速和电机输出为零，也不能有其他动作或待应用参数。

### 网页入口

1. 启动控制面板：`m6-tune --port COMx dashboard`。
2. 在原“八路灰度/标定”区域开始向导。
3. 全部探头置于背景，采集 64 帧；每路应稳定为 `4094`。
4. 全部探头覆盖黑线，采集 64 帧；每路应稳定为 `1`。
5. 八路全部通过后确认保存。保存的是兼容资格值，不是模块内部阈值。

### 红外遥控与 OLED 入口

| 操作 | 按键 | OLED 提示 |
|---|---|---|
| 开始或重启 | `5` | `IR CHECK` / `BG OK=START` |
| 采集背景 | `OK` | `BG CAPTURE` |
| 采集黑线 | `OK` | `LINE CAPTURE` |
| 确认保存 | `OK` | `CHECK OK=SAVE`，随后 `FLASH SAVED` |
| 取消 | `0` | `CANCELLED` |

每阶段需在 5 秒内获得 64 个不重复的成功扫描；等待人工操作超过 120 秒会取消。取消、掉线、急停、质量检查失败或 Flash 写入失败都保留旧值。

## 5. 方向和通信验收

1. 发送串口命令 `q`，确认输出仍包含 `GRAY adc=` 和 `GRAY ADC `，并看到 `transport=I2C`、`raw=0x..`、`nack`、`bus`、`recover`。
2. 逐个遮挡 IR1–IR8，确认原始掩码对应 Bit0–Bit7。
3. 将黑线移到车体左侧，逻辑位置应为负；移到右侧应为正。若相反，只切换 `GRAYSCALE_IR1_ON_RIGHT` 后重新构建。
4. 循迹动作中断开 SDA，确认成功快照不再刷新，并在 300 ms 内由 Safety 停车。

## 6. 常见故障

| 现象 | 处理 |
|---|---|
| 上电 3 秒后仍无扫描 | 检查 5 V、共地、PA24/PA26 和地址 `0x30` |
| `nack` 增长 | 检查模块供电、SDA/SCL 是否接反以及模块是否完成启动 |
| `bus`/`recover` 增长 | 检查短路、上拉、电平和线长；固件会进行最多 9 个 SCL 恢复脉冲 |
| 背景和黑线值相同 | 重新执行模块物理按键校准，检查探头高度和 ERROR 指示 |
| 左右方向相反 | 当前默认值为 `GRAYSCALE_IR1_ON_RIGHT=0`；若模块改为 IR1 在右侧则设为 `1`，不要改 M6 字段或循迹坐标定义 |

首次运动先让车轮离地，随后以 100 mm/s 落地验证，再提升到 160 mm/s。数字输入下是否需要调整循迹增益必须依据实车遥测决定。

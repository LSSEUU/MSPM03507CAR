## M1 串口诊断入口

上电后 UART0 使用 115200 baud、8N1。启动过程始终保持两路电机为制动状态，等待约 750 ms 收集 JY61P 和灰度样本，然后输出每项 `OK`、`DEGRADED` 或 `FAULT`、样本数、错误数和原因。

| 命令 | 作用 | 通过标准 |
|---|---|---|
| `s` | 输出全部自检状态 | 每项均有状态、样本数、错误数和原因 |
| `d` | 输出全部原始数据 | 包含编码器、JY61P、灰度和通信计数 |
| `e` | 编码器原始计数 | 手转两轮时相应 count/edge 持续变化 |
| `y` | JY61P 原始角度与帧统计 | `valid` 持续增加，checksum/frame 错误不持续增长 |
| `q` | 八路灰度原始位图 | 遮挡/移过黑白边界时 `raw` 位图发生对应变化 |
| `o` | OLED 棋盘格测试 | I²C 在 0x3C/0x3D 应答，屏幕显示棋盘格，输入 `p` 确认 |
| `l` | LED 能力说明 | 当前载板仅有电源灯，因此应报告 `DEGRADED` 和 0 个可控 LED |
| `c` | UART0 统计 | 每发送命令，RX 计数增加；输出使 TX 计数增加 |
| `m` | 双电机及编码器联动测试 | 架空车轮后输入大写 `A` 解锁；A/B 轮正反转且两路 edge 都增加 |
| `S` / 空格 | 电机急停 | 电机测试任一阶段立即制动并退出 |

电机测试安全要求：车轮必须架空，操作者必须能立即发送 `S` 或空格；未收到大写 `A` 前不会输出 PWM。测试按 A 正转、A 反转、B 正转、B 反转执行，每段 500 ms、PWM 250，每段之间制动。

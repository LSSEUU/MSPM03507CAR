# 0. 执行结论

当前不是“重新做一辆车”，而是在已存在的循线底盘上补齐三条闭环：

1. `MaixCAM Pro -> UART1 -> MSPM0` 的可信球位反馈；
2. `球位误差 -> 摆杆倾角命令 -> Emm42_V5.0` 的滚球闭环；
3. H2-H6 的本地任务状态机、圈/终点判定和联合安全。

外部图传已经能覆盖完整摆杆、场外实时显示、完整录像并回放，**不再开发自研图传接收器，也不要求 MaixCAM Pro 承担正式图传**。H1 只保留现场验收和留证。

当前最大风险按优先级排列：

1. **待实测：四杆机构的实际水平零位、方向、单调工作区和软限位尚未标定。** 3MF 已足够确定拓扑和名义尺寸，但打印误差、装配孔隙与实物初始角不能由 CAD 代替；
2. **待实测：视觉端到端延迟未知。** 已知识别约 20-30 FPS，帧率合格不等于控制延迟合格；
3. **待实测：新制作的完整赛道尚未跑车。** 历史记录不能证明 H2 所需约 307 mm/s 平均速度；
4. **待整合：车辆 Safety 尚未统一停止 Emm42 执行器。**

范围纪律：在 H1-H6 核心功能通过前，不做 Flash V3 迁移、不重做网页仪表盘、不开发新录像工具、不做无关重构。

## 1.3 H6 操作口径

赛题没有规定必须由裁判输入数字。本项目采用以下默认方案：

1. 车辆在 A 点静止，人工将钢球放在摆杆允许范围内的任意指定位置；
2. IDLE 状态维护最近 `300-500 ms` 有效球位样本；
3. 按下 K1 时，以合格样本的中值冻结本轮 `target_x`；
4. 目标在本轮运行中不可被网页、遥控或摄像头修改；
5. OLED 显示冻结目标、当前球位和误差。

若现场裁判另有口径，只调整启动前的目标采集步骤，不修改闭环控制器。

## 3.1 摆杆机构决策（拓扑已确认，待装车标定）

依据：

- `docs/Reference/H42装配+(2).3mf`，单位为 mm；
- `docs/Reference/装配实际图.jpg`；
- 3MF 内的装配变换和各零件网格孔心。

机构不是电机直驱摆杆，而是单自由度四杆机构：

```text
D：摆杆左侧固定铰点
A：Emm42 电机轴
B：输入摇臂与短连杆铰点
C：短连杆与摆杆活动端耳铰点

D ───────────── 摆杆/输出摇杆 ───────────── C
 \                                               /
  \ 固定机架                         短连杆 BC /
   \                                         /
    A ─────── 输入摇臂 AB ─────────────── B
```

从 3MF 名义网格提取的孔心距：

| 杆件 | 名义孔心距 |
|---|---:|
| 固定机架 `D-A` | 约 221.27 mm |
| 电机输入摇臂 `A-B` | 约 44.36 mm |
| 短连杆 `B-C` | 约 21.24 mm |
| 摆杆等效输出摇杆 `D-C` | 约 263.31 mm |

这些值用于确认机构类型和生成标定初值，不作为实物最终尺寸。按名义几何，最短杆与最长杆之和大于另外两杆之和，机构为非 Grashof 双摇杆：**电机输入臂不能连续整圈旋转，只能在一个无翻支、单调的局部工作区摆动。**

当前装配分支的 CAD 姿态约为摆杆 `-2.6°`；名义水平位附近对应输入摇臂绝对角约 `16.9°`。绝对角只用于识别装配分支，实际软件必须以 Emm42 原始位置和实测水平位重新置零。

固定工程决策：

- 优先使用 Emm42 **位置模式**，上层只给物理倾角目标；
- 禁止电机全周旋转，禁止跨越连杆共线、反向或近死点位置；
- `motor_position -> lever_angle` 使用 5-9 点分段线性查表，不使用单一 `counts_per_degree`；
- 软限位同时以电机位置和查表后的摆杆角度检查；
- 若位置命令不能覆盖旧目标，才退回速度模式；退回后仍必须由电机编码器约束在同一单调工作区；
- 球控制器、H 状态机和 Safety 不直接依赖四杆几何，只依赖 `LeverActuator_SetTilt()`。

仍需在实物上完成的标定：水平零位、正方向、可重复角度映射、两侧安全边界、回差和打印件挠度。这些属于 R0 台架标定，不再阻塞接口与文件结构的实施。

# 4. MaixCAM 球位接口合同

## 4.1 坐标与标定

- 坐标原点：摆杆中心 O；
- 正方向：按赛题图 3，沿摆杆向活动端/X 轴正向为正；
- 单位：协议使用 0.1 mm/LSB；界面可显示 cm；
- 有效控制范围初值：`[-115, +115] mm`，最终按机构可用槽长实测；
- 删除 `H_demo/main.py` 中用图像边缘覆盖手工标定端点的逻辑；
- 标定不得继续使用示例 `0..25 cm`。

标定点至少为：

```text
-100, -75, -50, -25, 0, +25, +50, +75, +100 mm
```

每点至少采 100 帧，记录中值、峰峰值和标准差。两点线性映射最大残差超过 5 mm 时改用分段线性映射，不用重滤波掩盖透视误差。

## 4.2 UART1 最小正式协议

采用小端固定二进制帧：

```text
A5 5A | version:u8 | type:u8 | payload_len:u8 | seq:u16 | payload | crc16
```

`BALL_MEAS` 载荷：

```text
flags:u8                 bit0 valid, bit1 in_range, bit2 off_axis
x_mm_x10:i16             O=0，活动端方向为正
vx_mm_s:i16              摆杆轴向速度
confidence:u8            0..255
axis_error_px_x10:u16    球心到标定轴线的垂距
capture_ms:u32           MaixCAM 单调时间，仅用于相邻帧诊断
```

要求：

- 每个识别周期都发帧；丢检时立即发送 `valid=0`；
- MCU 以本地接收时间判断新鲜度，不比较两台设备的绝对时钟；
- 显式 `valid=0` 立即清除测量有效状态；
- 恢复时连续 2 帧有效才重新允许控制；
- 无新帧超时初值为 150 ms，实测后可收紧；
- CRC16 可复用 `M6Wire_Crc16()` 算法，但 UART1 不复用 M6 会话状态机；
- UART1 原始字节监视保留，解析器是环形缓冲的唯一消费者，监视数据由复制或统计产生。

截止日前不实现 MCU→MaixCAM 的 `H_STATUS` 回传；正式图传已由外部系统承担，双向叠字不是得分前置条件。

## 4.3 视觉放行门槛

- 九点最大绝对误差 `≤5 mm`，重复放置标准差 `≤3 mm`；
- 识别与发送持续频率 `≥20 Hz`；
- UART 接收更新间隔 p95 `≤80 ms`；
- 遮挡后 `≤150 ms` 进入无效，恢复后 `≤200 ms` 重新有效；
- 10,000 帧噪声/分片/粘包/CRC/序号回绕测试不产生假有效坐标；
- 必须记录端到端运动响应延迟；若 p95 明显超过 120 ms，先降低视觉/通信延迟，不进入滚球 PID 调参。

# 5. 摆杆执行器合同

上层球控制器只输出物理意义明确的 `tilt_cmd`，不得直接散布 Emm42 脉冲数、方向符号或串口帧。

建议接口：

```c
bool LeverActuator_ArmHorizontal(uint32_t now_ms);
bool LeverActuator_SetTilt(float tilt_deg, uint32_t now_ms);
void LeverActuator_RequestStop(bool disable_after_stop);
void LeverActuator_GetSnapshot(LeverActuatorSnapshot_t *snapshot);
```

`LeverActuatorSnapshot_t` 至少包含：在线、使能、零位有效、电机位置、估计摆杆角、目标角、软限位、堵转/保护、最后响应时间和队列状态。

## 5.1 零位与限位

- 当前没有独立摆杆角度传感器，不假设自动回零；
- 比赛启动前允许人工将摆杆调到机械水平位，读取 Emm42 原始位置作为 `motor_zero`；确认不会破坏驱动器回零配置后，才可选择调用“当前位置清零”；
- 电机磁编码器只用于执行器位置状态和软限位；
- 以水平位为中心，在同一装配分支上分别向两侧做小步运动；每个点用数字水平仪/手机倾角仪，或用活动端高度变化与实测铰点距离换算摆杆角度；
- 至少采集 5 点，推荐 9 点，建立 `motor_position <-> lever_angle` 单调查表；正反向各重复 3 次，记录回差和重复误差；
- 任何点出现角度反向、变化率突增、连杆接近共线、打印件明显挠曲或机械干涉，立即停止并把该位置之外划为禁区；
- 初次闭环只开放实测摆杆 `±2°`，确认运动和停止可靠后再按需求逐步扩大；
- 软限位必须位于实测翻支/近死点和物理干涉之前，并保留明确机械裕量；
- 软件限位之外仍需检查物理干涉，任何映射越界立即拒绝命令；
- 零位无效时 H3-H6 均拒绝启动。

## 5.2 执行器 Go/No-Go

在滚球闭环前必须测量：

- 带摆杆负载时的最小可控动作；
- 命令到开始运动的延迟和 p95；
- 高频位置命令是覆盖旧目标还是排队；
- 紧急停止延迟；
- 电机位置/状态回读新鲜度；
- 正反方向、重复零位和软限位；
- 12 V 电池高低电量下的差异。

判定：

- 位置命令可覆盖、p95 响应 `≤50 ms`：优先位置模式；
- 位置命令排队但速度模式可即时更新：采用速度模式，并用电机编码器位置维护软件角度边界；
- 两种模式均无法及时覆盖旧目标或急停不可靠：停止 PID 调参，先修执行接口或机构。

# 6. 球控制器与 H3

## 6.1 控制律

小角度初始采用：

```text
e = target_x - x
tilt_cmd = Kp*e - Kd*vx + Ki*integral(e) + Kff*a_vehicle
```

处理顺序固定为：

1. 测量有效性检查；
2. 倾角限幅；
3. 倾角变化率限幅；
4. 饱和时冻结或回算积分；
5. 只有命令变化超过死区或到刷新期限才发 UART3；
6. 显式丢检时立即禁止积分并进入受控停止。

初期 `Ki=0`、`Kff=0`，只调 PD。不得在 MaixCAM 与 MCU 两端同时使用重滤波。

## 6.2 H3 状态机

```text
IDLE
 -> PREFLIGHT
 -> WAIT_O_VALID
 -> TARGET_PLUS_50
 -> SETTLE_PLUS_50
 -> TARGET_MINUS_50
 -> SETTLE_MINUS_50
 -> COMPLETE / FAULT
```

初始判定：

- 启动前 `|x|≤5 mm` 且有效持续 300 ms；
- 到达目标：`|e|≤5 mm`、`|vx|≤20 mm/s` 持续 250 ms；
- 视觉超时、位置越界、软限位、步进保护或任务超时立即失败；
- H3 放行：连续 5 次 `≤4.5 s`，两个稳定段最大误差 `≤7 mm`。

# 7. 车辆任务与起终点

## 7.1 启停线检测

独立检测器消费同一份灰度快照，不修改现有巡线算法的单线语义。

候选事件特征必须由新赛道录制数据标定：

- 多数通道同时变黑或黑度总和突增；
- 连续多个完整扫描；
- 事件前后回到普通单线；
- 已离开起点并满足最小里程/时间；
- 终点事件只在约 `5.3-6.8 m` 的末圈窗口内有效。

不得仅靠编码器里程结束，也不得仅靠一次全黑结束。

## 7.2 停车几何

实施前必须测量：

```text
sensor_to_test_point_mm
```

即灰度阵列参考线到车体唯一测试点的有符号纵向距离。检测终点横线后进入低速爬行，再按标定偏移停止并冻结计时。

`stop_offset_mm` 只根据至少 10 次带符号停车误差的中值调整，不根据单次打滑修改。

## 7.3 B 点

B 点无额外标线，用左右编码器平均里程判定：

```text
progress_mm = 0.5 * (left_distance_mm + right_distance_mm)
B_passed when progress_mm >= 1500 mm + calibrated_margin
```

H4 可在确认通过 B 后受控停车。

## 7.4 速度边界

- H2 平均速度至少约 307 mm/s，属于尚未验证的高速任务；
- H2 与 H5/H6 使用不同速度档；
- 新赛道必须从低速开始分级放行，未通过当前速度不得直接加速；
- H4 首先只做 A→B，不用整圈问题干扰车球联合调试；
- H5/H6 优先稳定，目标圈时 23-28 s。

# 8. H 任务状态机与本地操作

## 8.1 按键

- K2：上一个模式；
- K3：下一个模式；
- K1：确认/启动；
- 20-30 ms 软件去抖；
- 蜂鸣器短鸣 Ready、双短鸣完成、长鸣拒绝/故障。

H2-H6 必须由车载 K1 启动，不能依赖网页启动。H1 不是运动模式，只做图传验收。

## 8.2 公共状态

```c
IDLE
PREFLIGHT
READY
RUNNING
FINAL_APPROACH
COMPLETE
ABORTED
FAULT
```

## 8.3 启动前检查

公共要求：

- SystemState 为 IDLE，无 Safety fault；
- 无手动驾驶、诊断动作、灰度标定或待应用参数；
- 车辆轮速和 PWM 为零；
- 行驶模式要求灰度、线和编码器有效；
- 滚球模式要求视觉新鲜、执行器在线、零位有效、无保护/限位；
- 队员确认外部图传正在显示和录像，但不让网络 ACK 阻塞实时系统；
- H3 要求球位接近 O；H4/H5 要求目标 O；H6 要求目标采样合格。

按下 K1 后才清零并启动赛题计时。

## 8.4 模式完成条件

| 模式 | 完成条件 |
|---|---|
| H2 | 完成一圈、识别 A 横线、按停车偏移停稳并冻结计时 |
| H3 | 完成 +5 cm 与 -5 cm 两个稳定段 |
| H4 | 编码器确认通过 B，随后受控停车 |
| H5 | 通过末圈 A 横线，随后受控停车 |
| H6 | 通过末圈 A 横线，随后受控停车 |

## 8.5 运行锁

RUNNING 时拒绝：IR 行驶、WASD、普通动作 Arm、参数 Apply/Save、灰度标定和独立步进测试。UART0 只保留遥测与急停；断线后不重放任何命令。

# 9. 联合 Safety

## 9.1 故障

至少覆盖：

```text
BALL_VISION_TIMEOUT
BALL_OUT_OF_RANGE
STEPPER_TIMEOUT
STEPPER_PROTECTION_OR_STALL
LEVER_SOFT_LIMIT
H_MISSION_TIMEOUT
START_LINE_INVALID
LINE_LOST
```

## 9.2 统一停止

任何 H 任务硬故障必须同时：

1. 车辆电机主动制动；
2. 停止继续产生摆杆目标；
3. 用 UART3 紧急批次抢占尚未发送的普通帧，发送停止，必要时失能；
4. 冻结计时和首故障；
5. 保留遥测和录像，不自动清故障继续本轮。

不得在中断里等待 UART。中断或急停回调只设置高优先级停止请求，由现有非阻塞发送路径完成。

## 9.3 失效分级

- 显式丢检或置信度不足：立即停积分；短时间未恢复则车辆受控减速、摆杆回安全状态并判本轮失败；
- 视觉 UART 超时：按 150 ms 初值触发失败；
- 步进保护、软限位、调度超期或完全丢线：立即统一停止并锁存故障；
- 任何故障都不得自动恢复本轮运动。

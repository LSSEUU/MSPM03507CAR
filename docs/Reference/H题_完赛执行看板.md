## 每次测试

```text
身份核对 -> 机械/电源 -> 图传和录像 -> Ready检查
-> 物理K1启动 -> 无干预运行 -> 停止录制
-> 先判硬失败 -> 只改一组参数 -> Apply复测 -> 重复通过后Save
```

## 硬失败

- 任意 Safety fault；
- 脱线、编码器无效或堵转；
- 视觉超时/错误使用旧坐标；
- 步进堵转、限位、掉电或命令队列失控；
- UART/遥测 gap、调度超期；
- 持续角度/PWM饱和；
- 录像不完整。

硬失败后急停并保留数据，禁止自动清故障继续跑。

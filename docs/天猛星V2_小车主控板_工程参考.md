### 网名约定

- `VCC` 由核心板的 `3V3` 脚引出，因此本文按 **3.3 V** 处理。
- `+5V` 由核心板的 `5V` 脚引出。`VCC` 与 `+5V` 不是同一电源网。
- GPIO 网名省略了模块符号中的前导零，例如 `A0 = A00`、`B2 = B02`。
- 表格中的“方向”均以主控板为参照。

## 2. 先看这些工程注意事项

1. **不要把 `VCC` 与 `+5V` 直接短接。** `VCC` 是 3.3 V。
2. 八路灰度连接器的供电脚由 `R1/R2` 二选一：`R1` 选 `+5V`，`R2` 选 `VCC`。当前实物已确认使用 `VCC`（3.3 V），不得同时接入 `+5V`。
3. 霍尔编码器接口的 `ADC` 脚只出现在连接器处，图中没有接到 MCU。
4. `MOTOR` 7P 接口没有 GND 和电机电源脚，外部驱动板必须通过其他路径与主控共地。
5. `AGND` 在图中是独立网，只连接核心板 AGND 与 H10-18，未画出与数字 GND 的连接点。
6. 当前霍尔编码器和灰度传感器均使用 3.3 V，与 MCU GPIO 电平一致；摄像头接口为 5 V 供电且图中未见电平转换，接入前仍需确认其输出电平兼容。
7. 扩展口与板上外设共用同一批 GPIO。扩展外设不得与已占用功能同时驱动同一网络。

## 8. 固件资源占用建议

| 资源 | 建议固件定义 | 注意点 |
|---|---|---|
| 电机 | 6 个输出：B2、B3、A17、A16、A14、A13 | B2/B3 需配置到合适的 PWM/定时器功能；具体复用以 MCU 数据手册为准 |
| 灰度 | A23、A24、A26、A25 输入 | 当前供电为 3.3 V；根据传感器输出类型选择 ADC 或数字输入模式 |
| 霍尔 | A8、A9、B9、B8 输入 | 当前供电为 3.3 V；建议使用定时器捕获或外部中断 |
| OLED | A28/A31 I²C | 板上已有 4.7 kΩ 上拉，避免外设端叠加过多低阻上拉 |
| UART | UART0-3 如上表 | 初始化前统一定义“MCU RX/TX”与“外设 RX/TX”，避免按同名直连 |
| 按键 | B18、B19、B17 输入 | 空闲低、按下高；软件去抖可按 10-30 ms 起步 |
| 旋转编码器 | A7、B10、B11 输入 | A/B 建议中断或定时采样，SW 单独去抖 |
| 蜂鸣器 | A18 输出 | 若是无源蜂鸣器需 PWM；若是有源蜂鸣器可普通 GPIO |

## 9. 上电与联调检查清单

- [ ] 断电确认 `VCC` 与 `+5V` 不短路。
- [ ] 测量 `VCC` 约为 3.3 V、`+5V` 约为 5 V。
- [x] 灰度接口当前使用 3.3 V 供电。
- [x] 霍尔编码器当前使用 3.3 V 供电。
- [ ] 外部电机驱动与主控建立可靠共地。
- [ ] 接入摄像头前检查其信号高电平不会超过 MCU 允许范围。
- [ ] UART 逐路做 TX/RX 回环或示波器检查，确认交叉关系。
